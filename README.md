## 🌌 Welcome to Golden Space

JARVIS is a cinematic AI-assistant project combining a futuristic interface, real-time interaction, conversational AI and speech technologies.

**Project identity:** Midnight Black × Metallic Gold × Intelligent Automation.

## 🧠 Technology Stack

| Layer | Technology |
|---|---|
| Frontend | React 19, TypeScript, Vite |
| Interface | Tailwind CSS, Lucide Icons |
| 3D Visuals | Three.js, React Three Fiber |
| AI Brain | Google Gemini |
| Voice Engines | Fish Audio, ElevenLabs, Web Speech |
| Backend | Node.js, Express, WebSocket |
| Voice Microservice | Python |
| Gesture Processing | MediaPipe |

## ✨ Features in the Codebase

**Golden AI Core** — An animated, state-reactive cinematic interface.

**Conversational AI** — Gemini backend integration for intelligent responses.

**Voice Architecture** — Hindi/Hinglish speech processing and configurable text-to-speech providers.

**3D Experiences** — Interactive avatars, visual effects and galaxy-inspired interfaces.

**Gesture Interface** — Camera and hand-gesture detection components.

**Desktop Architecture** — Dedicated desktop UI components and backend services.

*Note: Presence in the source code does not guarantee that every feature is configured or working on every device.*

## 🎙️ Voice Configuration

JARVIS supports configurable voice providers. For a natural male voice, select a compatible ElevenLabs voice and configure its Voice ID locally.

Keep API keys private. Never commit `.env` or credentials to GitHub.

## 🚀 Getting Started

```powershell
git clone https://github.com/MohitLovanshi372/mgite-software.git
cd mgite-software
npm install
Copy-Item .env.example .env
npm run dev
```

Open `http://localhost:3000`.

API-backed features require valid local configuration. Environment loading and the Windows Python voice bridge should be verified before relying on voice integration.
